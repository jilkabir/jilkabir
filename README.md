### ✨ Project spotlight — Miroo Brand Maker

A **Next.js + TypeScript + Tailwind CSS** prototype that turns a website URL into a starter brand-strategy report, including color direction, audience positioning, social content pillars, and caption ideas. It can use the **OpenAI Responses API** and includes a mock fallback for demo mode.
